# (auto)-discipher

a library to parse network packets from a certain tv anime game!

## use in your projects

not published to crates.io out of caution. add following to your Cargo.toml to use

```toml
[dependencies]
auto_discipher = { git = "https://github.com/hashblen/auto-discipher" } # optionally add revision
```

for documentation, use `cargo doc`
